**Concrete steps.** Reproduce locally what the runner does:

```bash
# 1. Start mitmproxy and point the emulator's proxy at it
mitmweb --listen-port 8081 &
adb shell settings put global http_proxy 10.0.2.2:8081

# 2. Launch the app and watch the flow list
adb shell am start -n org.masdojo.pulse/.MainActivity
```

Find the `POST` to `/api/v1/telemetry`. Open its request body — it's a urlencoded
form with a `device_token=...` field. That token (it looks like `FLAG{...}`) is
what you submit in the **value** field.
