**Concrete steps.**

```bash
# Decompile the APK you downloaded from the skill map
jadx -d vaultbank_src MASDojo.apk

# Search the decompiled source for the key. The prefix is a giveaway.
grep -rn "msd_live_sk_" vaultbank_src/
# or look at:
#   vaultbank_src/sources/org/masdojo/vaultbank/BuildConfig.java   (API_KEY)
#   vaultbank_src/sources/org/masdojo/vaultbank/ApiConfig.java     (apiKey / Bearer header)
```

The key follows the format `msd_live_sk_` + 32 hex characters. Copy the full
value (including the prefix) and submit it.
