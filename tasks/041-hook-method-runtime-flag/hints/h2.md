**Technique pointer.** Dynamic instrumentation (MASVS-RESILIENCE-1): in `org.masdojo.vaultbank.DashboardActivity` the dashboard calls `computeReward()` on startup but only logs its *length* - the value itself never reaches the UI or logcat.
