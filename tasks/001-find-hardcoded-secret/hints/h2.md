**Technique pointer.** This is MASTG's "reviewing decompiled code" technique (MASVS-STORAGE-1). Open `target.apk` in **jadx-gui** (or run `jadx -d out target.apk`) and browse the app's own package, `org.masdojo.securenotes`. Pay special attention to `BuildConfig` and any class that builds network requests — keys are often stashed in a constant or an `Authorization` header.
