**Concrete steps.**

```bash
apktool d MASDojo.apk -o vb
# Find the gate and flip its return to true (0x1):
grep -rn "isPremiumUser" vb/smali*/org/masdojo/vaultbank/DashboardActivity.smali
#   .method private final isPremiumUser()Z
#       const/4 v0, 0x0     <-- change to:  const/4 v0, 0x1
#       return v0
apktool b vb -o vb-patched.apk
# Re-sign (debug key) and install:
apksigner sign --ks ~/.android/debug.keystore --ks-pass pass:android vb-patched.apk
adb install -r vb-patched.apk
```
