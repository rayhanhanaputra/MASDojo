**Technique pointer.** Certificate-pinning bypass (MASVS-NETWORK-2 / RESILIENCE-1): the app enforces the pin with OkHttp's `okhttp3.CertificatePinner.check(hostname, peerCertificates)`, which **throws** when the presented certificate doesn't match the pin. Hook that method so it returns without throwing, and pinning no longer blocks the connection. The pin is evaluated on the RASP lab screen (`vaultbank://rasplab`).
