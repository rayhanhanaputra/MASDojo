**Concrete steps.** The token verifier trusts the header `alg`, so an unsigned `alg:none` token is accepted.

- **Live API (Lab 3):** a normal token from `http://localhost:8091/login` is refused by `GET /admin/ledger` (role=user). Forge a token with header `{"alg":"none"}` and payload `{"role":"admin"}` and an empty signature, then call `/admin/ledger` to get the flag.
