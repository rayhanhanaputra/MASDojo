**Concrete steps.**

```bash
apktool d MASDojo.apk -o vb
# Find the gate and flip its return to true (0x1):
grep -rn "isPremiumUser" vb/smali*/org/masdojo/vaultbank/DashboardActivity.smali
#   .method private final isPremiumUser()Z
#       const/4 v0, 0x0     <-- change to:  const/4 v0, 0x1
#       return v0
apktool b vb -o vb-patched.apk
# Zipalign + re-sign with a debug key (a fresh debug key is fine):
zipalign -f 4 vb-patched.apk vb-aligned.apk
apksigner sign --ks ~/.android/debug.keystore --ks-pass pass:android vb-aligned.apk
```

Then **upload `vb-aligned.apk`** as your submission. The runner installs your
build, launches it, and checks the premium path unlocks at runtime - so you must
actually patch and re-sign; recovering the flag string statically won't pass.
